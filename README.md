# Prasanna Kumar J Portfolio

Modern Vue 3 portfolio website for Prasanna Kumar J, built with Vite, Tailwind CSS, VueUse Motion, and Lucide icons.

## Project Structure

```text
public/
  assets/
    prasanna-profile.jpg
    prasanna-kumar-j-resume.pdf
src/
  components/
    AboutSection.vue
    AchievementsSection.vue
    ContactSection.vue
    GitHubStats.vue
    HeroSection.vue
    LoadingScreen.vue
    Navbar.vue
    ProjectsSection.vue
    SectionHeading.vue
    SiteFooter.vue
    SkillsSection.vue
    TimelineSection.vue
  App.vue
  data.js
  main.js
  style.css
```

## Commands

```sh
npm install
npm run dev
npm run build
```

The site is optimized for static deployment on Netlify, Vercel, or any Vite-compatible host.
